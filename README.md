## Version ALLROUND 101 MIGRATION FIX

Diese Version erzwingt eine neue lokale Datenbasis `MRP_ALLROUND_2026_V2`.
Alte Browserdaten mit nur ca. 31 Netzbetreibern überschreiben die neue Startliste nicht mehr.

Nach dem Hochladen:
1. GitHub Pages öffnen
2. STRG + F5 drücken
3. Falls iPhone Homescreen App genutzt wird: alte Homescreen App löschen und neu hinzufügen
4. In der App unter Backup / Daten → Startlisten neu einlesen klicken
